# Maintained release materials

This folder is the source of the dependency notices and distribution documents
bundled with portable Sidro releases. Keep the canonical copies here, since
`dist` is generated by the release builder.

| Path | Purpose |
|---|---|
| [DEPENDENCY_BASELINE.md](DEPENDENCY_BASELINE.md) | Tested package baseline, accepted compatibility exceptions and packaging profile. |
| [RELEASE_REQUIREMENTS.md](RELEASE_REQUIREMENTS.md) | Required package contents and release verification workflow. |
| [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) | Independent dependency/model notices and distribution terms. |
| [licenses/qt](licenses/qt) | Qt/PySide license texts, version manifest and source/replacement instructions. |
| [licenses/supplemental](licenses/supplemental) | Additional upstream license texts and native-library notices. |
| [licenses/NATIVE_SOURCES_AND_REPLACEMENT.md](licenses/NATIVE_SOURCES_AND_REPLACEMENT.md) | Source and replacement information for native dependencies. |
| [sources/manifest.json](sources/manifest.json) | Expected upstream source archives, download URLs and verified hashes. |

The shared development baseline contains optional dependencies; its maintained
notices may therefore cover more packages than the RapidOCR-only portable app.
The builder selects the materials needed for the shipped package.

Large upstream source archives are omitted from Git source publication. Maintainer
builders obtain the exact archives listed by the manifests and include required
archives in the portable release. The bundler and ZIP validator check those
obligations. Sidro's own [MIT license](../LICENSE) is copied into every release.
